**Source:** docs/cleanup/audit.md (12 Oct 2026). **Decisions (Jenish, 12 Oct):** D1 delete the parked futures code, keep the DB columns; D2 delete the unused shadcn components and their packages; D3 delete the stale e2e now, fresh e2e for steps 03–05 only when asked; D4 unit tests keep behaviour only, no copy or config tables.
**Goal:** remove what the audit found with no behaviour change on any live screen.
**Test layers:** unit only, as the code it touches. Every task ends with `bun test` on what it touched, `bun run type-check`, `bun run lint`; the controller runs `bun run test:run` once at the end and compares screenshots after task 3. E2E specs are edited, never run (CLAUDE.md: only when asked).
