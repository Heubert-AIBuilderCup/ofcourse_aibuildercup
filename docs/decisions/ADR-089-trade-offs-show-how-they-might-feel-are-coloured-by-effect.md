# ADR-089 · Trade-offs show how they might feel, are coloured by effect, and come with ways to offset the downsides

## Decision

- Each trade-off line is marked **gives you / costs you / neutral** with colour *and* a shape or word (never colour alone, ADR-046).
- A small **"how this might feel"** indicator (e.g. relieved / fine / stretched / hard) derived by rules from the size of the effect and how much the student weights that dimension; never generated by the model, never shown as a verdict.
- Every "costs you" line offers **ways to offset it**, grounded in the knowledge base with sources (Gen AI use case G10), counsellor-reviewed and reused.

## Reasoning

A downside the student can act on is less frightening and more useful than one they can only read (Nikhil, 2 Oct). Colour alone fails colour-blind users; feelings must be honest and rule-based, not invented.
