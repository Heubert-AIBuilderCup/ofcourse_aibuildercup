# ADR-020 · Four admin roles

## Decision

Editor (draft, approve structure, render), reviewer (publish regulated content), counsellor (view student plans, comment), admin (roles, budgets).

## Reasoning

- Matches the two-stage generation and tiered publishing; separates making from approving regulated claims.

## Constrains

Personal data visibility follows role. Resolves D12.
